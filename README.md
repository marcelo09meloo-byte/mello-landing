# Mello.ads Landing Page

Landing page premium em HTML5, CSS3 e JavaScript ES6, pronta para publicação na Netlify.

## Estrutura

- `index.html`: página principal com SEO técnico, Open Graph, Twitter Cards e JSON-LD.
- `style.css`: sistema visual responsivo com glassmorphism, gradientes, microinterações e acessibilidade.
- `script.js`: menu mobile, scroll reveal, partículas, cursor e validação do formulário.
- `assets/`: imagens SVG otimizadas e ícones.
- `manifest.json`, `robots.txt`, `sitemap.xml` e `404.html`: arquivos de publicação.

## Publicação na Netlify

Arraste a pasta do projeto para o deploy manual da Netlify ou conecte este repositório. Como é um site estático, não há comando de build.
